Export a self-contained index.html with your exact current layout permanently baked in as DEFAULT_LAYOUT_STATE

Step 1 • Download Ready-to-Commit Repository Files

Downloading index.html automatically injects your current canvas items, wall geometry, doors, and 3D models as the permanent DEFAULT_LAYOUT_STATE.

Step 2 • Create GitHub Repository & Publish to GitHub Pages

Run these commands in the folder where you saved index.html and README.md:

# 1. Initialize Git repository in the folder containing your downloaded index.html & README.md
git init
git branch -M main
git add index.html README.md
git commit -m "Initialize Concordia Genome Foundry 2D/3D Layout & Schematic Studio"

# 2. Create public GitHub repository & push (using GitHub CLI 'gh')
gh repo create genome-foundry-layout --public --source=. --remote=origin --push

# 3. Enable GitHub Pages on the 'main' branch root
gh api -X POST repos/:owner/genome-foundry-layout/pages -f source[branch]=main -f source[path]=/

# Your live interactive 2D/3D studio will be published at:
# https://<your-github-username>.github.io/genome-foundry-layout/
